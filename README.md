Pageline – AI Landing Page Optimizer

Pageline is an AI-powered web application that analyzes landing pages and provides actionable recommendations to improve conversion rates, SEO, accessibility, and user experience.

The application generates detailed optimization reports with AI-powered suggestions, competitor insights, and downloadable PDF reports.

 📌 Features

- 🔐 User Authentication (Login & Signup)
- 👤 Guest Mode for demo users
- 📊 Landing Page Analysis
- 🤖 AI-powered recommendations
- 📈 SEO Score
- ♿ Accessibility Score
- 💰 Conversion Potential Score
- 🎨 Color Psychology Recommendations
- 📝 Headline & CTA Suggestions
- 🏆 Competitor Gap Analysis
- 🔍 SEO Keyword Suggestions
- 📄 Download Report as PDF
- ☁️ Supabase Authentication & Database Integration
- 📱 Responsive UI Design

## ⚙️ How to Run

1. Clone the repository

```bash
git clone https://github.com/jahnavinarayanasetty/PageCraft
```

2. Open the project folder

```bash
cd pageline-ai-landing-optimizer
```

3. Open `index.html` in your browser

or use VS Code Live Server.

---

## 🔑 Supabase Setup

1. Create a Supabase project.
2. Copy the Project URL and Anon Key.
3. Replace them in the JavaScript configuration.

```javascript
const SUPABASE_URL = "YOUR_SUPABASE_URL";
const SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_KEY";
```

4. Enable Email Authentication in Supabase.
